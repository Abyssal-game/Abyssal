# ABYSSAL — French → English translation brief

ABYSSAL — The Forbidden Bestiary is a dark-fantasy collectible card game for iPhone (500 creatures from world mythologies, 7 factions, boosters, a 100-floor roguelike "Descent" with turn-based tactical combat, mini card games, achievements).

## Output format (strict)
- Input: a JSON array of French strings (UI texts). Output: ONE JSON object `{ "<french string exactly as given>": "<english translation>", ... }` with EVERY input string as a key, unchanged byte for byte (same quotes ’ « », same spaces, same accents).
- Keep every placeholder exactly: `{0}`, `{1}`… are numbers; `{e0}`, `{e1}`… are icons/badges/elements. Each placeholder must appear in the translation exactly as many times as in the French (you may reorder them).
- Keep HTML tags (`<b>`, `</b>`, `<i>`, `<small>`, `<br>`, `<em>`, `<strong>`, `<u>`) — same tags, balanced; wrap the equivalent English words.
- Keep leading/trailing punctuation style. Keep « » quotes as “ ” in English. French narrow spaces before ? ! : ; are dropped in English.
- If a string is not real UI text (a code identifier, CSS, a file name, a lone fragment that cannot be translated), map it to itself (same string).
- If a string is a proper name of a person/creature/character not listed in the glossary, keep it as is (e.g. Ilda, Mammon, Vesna).
- Never add explanations or comments in the JSON.

## Tone
- The game speaks to the player with the informal French « tu » → plain direct English "you". Short, punchy, game-UI style. Buttons in Title Case only when short labels (e.g. "Open", "Start chapter"); sentences in sentence case.
- Dark-fantasy flavour where the French has it (lore lines, guardian quips), neutral and clear for rules/help.
- Numbers formatting is handled by the game; leave {0} as is.
