Noms des créatures (export `names`) : un nom propre de mythologie se garde dans sa forme usuelle de la langue (Lilith, Fenrir, Tiamat ; Lucifer ; Hel ; « Héphaïstos » → es Hefesto, de Hephaistos, it Efesto, pt Hefesto). Un nom descriptif se traduit (« Le Rêveur Sous la Fosse » → es « El Soñador bajo la Fosa »). « … Lignée » → es « Linaje de … », de « Blutlinie … » / « …-Blutlinie », it « Stirpe di … », pt « Linhagem de … ».
